# 未完成与待实机确认

当前已包含账号与权限、患者和计划、每周日程、前后反馈、教学版本缓存、真实训练记录及条件分组趋势。下列能力仍未完成或需要真实环境确认：

- Jetson ARM64 依赖安装、H.264 编解码、六动作性能、长时间热状态及恢复。
- 模拟器真实 RTC 联调结束后，独立测试服务的关闭曾超过 30 秒；需复核真实模型和连接资源的退出耗时。
- 实体手机/机器人屏幕上的摄像头方向、字号、中文 TTS、网络抖动与前后台处理。
- Android 旧版本兼容：最低 API 21，但日期解析格式 XXX 需要 API 24，forceDarkAllowed 主题属性需要 API 29；这是现有 Lint 问题，尚未修复。
- 真实 SMTP 收信、密码找回和实际备份恢复演练。
- 多患者、多机位的逐次人工动作对照、漏计/误计统计、内容专业审核与患者可用性研究。
- 人工复核队列与结论、审计查询、报告打印导出、工作人员备注保存、App 备份恢复。现有对应页面为明确禁用的占位入口，命令行备份工具可用。
- 机构级账号管理、数据保留和销毁政策、多设备并发及跨机构隔离。当前单客户端服务不支持多 worker 扩容。
- 模型权重与教学资产商业分发许可。

项目是训练辅助原型，算法合格次数不能解释成临床评分或疗效。当前视觉不能证明实际接触、施力、疼痛或抓握安全；动作规则与证据边界见 [action_rules.md](action_rules.md)。
